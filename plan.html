1한 장 요약

11월 17일(월)에 "사진 속 그 나무를 그대로 받고, 받기 전에 화분·철사·사리 작업까지 주문하는" 분재 전문몰 이키본을 엽니다. 사이트와 모든 계정은 홍씨 소유이고, 홍씨는 나무·손 작업·발송을, 김씨는 개발·마케팅·자동화를 맡습니다.

홍씨

홍씨가 하실 일

날짜가 있는 것은 그 날짜가 전체 일정을 정합니다. 하나라도 늦으면 오픈이 그만큼 밀립니다.

  1. 10.24까지
    명의 만들기. 사업자등록·통신판매업 신고, 결제사 계약 신청, 도메인, 카카오 채널, 네이버·인스타·유튜브 계정 개설. 전부 홍씨 명의로 만들고, 김씨에게는 관리자 권한만 주시면 됩니다. 순서와 방법은 김씨가 옆에서 안내합니다.
  2. 10.24까지
    가격 정하기. 철사걸이·분갈이 공임표와 사리 작업 가격대. 이 문서에 적힌 금액은 전부 예시입니다.
  3. 10.31까지
    나무 20그루 사진과 규격. 그루당 사진 6장(정면·좌·우·뒷면·뿌리·수피)과 수고·수폭·목대·근장·수령·가격. 휴대폰 사진이면 됩니다.
  4. 11.3~7
    작업 영상 3편. 철사 감는 손, 분갈이, 사리 다듬는 장면 같은 것. 편집은 자동으로 합니다.
  5. 11.10~14
    시험 주문 발송. 지인 10명이 실제로 주문한 나무를 포장해 택배로 보내 봅니다.
  6. —
    함께 정할 것 5가지에 답 주기 (8절). 대부분 "추천대로"라고만 하셔도 됩니다.

오픈 뒤에 홍씨가 계속 하시는 일은 네 가지입니다. 손 작업(사리·철사걸이·분갈이), 포장과 택배 발송, 텔레그램으로 오는 사리 견적 확인, 그리고 AI가 못 푼 고객 문의(환불·고사 분쟁·전문 질문) 응대입니다. 나머지는 자동으로 돌아갑니다.

왜 지금, 왜 이렇게

국내에는 "옵션 서비스가 붙은 분재 전문 온라인몰"이 없습니다. 유럽 분재몰(Bonsai Plaza)이 파는 나무 중 다수가 한국산이고(소사나무 61cm 30년생이 995유로), 한국은 생산국인데 국내 전문몰이 거의 없습니다. 그 빈자리를 먼저 차지하는 게 목표입니다.

11월 오픈은 분갈이 적기(2~3월)와는 안 맞지만 송백류 철사걸이 적기(늦가을~겨울)와는 맞습니다. 첫 석 달은 나무 판매 + 철사걸이 공임 + 봄 분갈이 예약 접수로 가고, 2월부터 분갈이 주문을 받습니다. 매출이 꾸준히 나올 곳은 분갈이·철사걸이 공임이고, 사리 AI는 사람을 불러오는 간판입니다.

2무엇을 만드는가 — 손님이 겪는 한 바퀴

손님 입장에서 사이트는 이렇게 돌아갑니다.

1나무 고르기

나무 한 그루 = 상품 하나. 품번, 사진 8장, 수고·수폭·목대·근장. 사진 속 그 나무가 그대로 갑니다.

2옵션 고르기

분갈이(화분), 철사걸이, 사리 AI 미리보기. 적기가 아니면 화면이 먼저 알려줍니다.

3결제

카카오·네이버 로그인, 도로명주소, 네이버페이·카카오페이. 한국식 그대로.

4받기

월·화에만 발송. 폭염·한파 특보가 뜨면 자동으로 미룹니다.

5내 분재 일지

받는 순간 자동으로 생깁니다. 홍씨의 작업 사진이 들어가고, 물 주기·철사 제거·분갈이 시기가 알림톡으로.

6물어보고, 다시 주문

질문에 홍씨 이름으로 답(초안은 AI, 확인은 홍씨). 알림을 받고 다시 들어와 다음 작업을 주문.

쉽게 말하면중고차 매물처럼 한 대 한 대가 다 다른 상품이고, 산 뒤에는 정비 알림이 오는 구조입니다. 쇼핑몰과 커뮤니티가 같은 로그인·같은 데이터 위에 있어서 "산 나무 → 키우는 기록 → 다음 작업 주문"이 끊기지 않습니다.

화면 10개를 실제처럼 만들어 둔 데모가 여기에 있습니다. 화면 속 버튼을 누르면 다음 화면으로 넘어갑니다. 사진은 위키미디어 공용(CC 라이선스) 실제 분재 사진이고, 나무 이름·가격·치수는 예시입니다. 화면별 설명은 부록 A에 있습니다.

3옵션 서비스 세 가지 — 이 사이트의 핵심

겉으로는 쿠팡에서 색상·사이즈 고르듯 보이지만, 세 옵션은 안에서 돌아가는 방식이 다릅니다. 나무는 살아 있고 작업에는 "때"가 있기 때문입니다.

시기가 핵심 · 주문 시 결제
분갈이
적기 판정 → 적기 아니면 선택 → 화분+공임 결제
사이트가 오늘 날짜와 수종을 보고 "지금은 적기가 아닙니다"를 자동 판단. 적기가 아니면 세 가지 중 고르게 합니다: 임시 화분으로 먼저 받고 봄에 무료 시공(기본값), 이키본에 보관, 직접 하기. 임시 화분도 팔리고, 봄에 손님이 다시 옵니다.
가장 단순 · 주문 시 결제
철사걸이
공임표로 바로 결제 → 7일 작업 → 제거 알림 예약
크기(소·중·대품)와 난이도(잡목 쉬움, 송백 어려움)로 공임이 정해져 있습니다(예시: 소품 3만 / 중품 6만 / 대품 12만~). 작업 기간(7일)만큼 발송이 미뤄지고, 수종별 개월 수(송백 8개월, 잡목 4개월)를 더해 "철사 제거 알림"이 자동 등록. 이 알림이 손님이 다시 오는 가장 확실한 이유.
두 단계 · 승인 후 결제
사리·신
AI 그림 3안 → 홍씨 견적(2일 내) → 승인 → 작업비 결제
손님이 AI 그림 3안 중 하나를 고르고 원하는 느낌을 적으면, 주문에는 "사리 요청"만 붙고 나무값만 결제됩니다. 홍씨가 실제 나무를 보고(살아 있는 물길 위치, 껍질 상태) 가능 범위·확정 금액·기간을 정해 알림톡으로 보내고, 손님이 승인하면 그때 작업비 결제. 마음에 안 들면 나무만 받습니다. 송백류만.
쉽게 말하면사리는 되돌릴 수 없는 작업이라 그림대로 자동 진행하면 반드시 분쟁이 납니다. AI 그림은 "방향을 정하는 도구"이지 "결과 약속"이 아닙니다. 데모 05번 화면에 이 문구가 그대로 들어가 있습니다.

사리 미리보기 그림은 나무 정면 사진을 이미지 편집 AI(사진을 주면 일부를 바꿔 그려주는 모델)에 넣어 만듭니다. 어느 모델이 가장 그럴듯하게 그리는지는 홍씨 나무 사진 5장으로 시험해 보고 정합니다.

4홍씨와 김씨가 나누는 일

원칙은 하나입니다. 소유는 홍씨, 자동화는 김씨. 사이트·도메인·서버·결제사 계약·카카오 채널·네이버·인스타·유튜브 계정은 전부 홍씨 명의이고, 김씨는 관리자 권한으로만 들어갑니다. AI가 할 수 있는 일은 전부 김씨 쪽에서 세팅하고 책임집니다.

구분홍씨 (소유주)김씨 (개발·운영)
소유권·명의사이트, 도메인, 서버·깃허브 계정, 결제사 계약, 카카오 채널, 네이버·인스타·유튜브 계정 — 모두 홍씨 명의관리자 권한으로 접근. 명의는 가지지 않음
나무·상품 정보나무 확보, 사진 촬영, 규격·수령·가격 정보 제공받은 사진·정보를 상품으로 등록 (자동화)
손 작업사리·신, 철사걸이, 분갈이 시공. 사리 견적 판단견적 초안·작업 일정·고객 안내는 AI가 준비
포장·발송포장하고 택배 보내기발송 요일 계산, 송장 발급·등록, 특보 보류, 고객 알림톡 — 자동화
고객 응대AI가 못 푸는 건(환불·고사 분쟁, 전문 질문) 2차 응대1차 응대 AI 세팅, 전달 규칙 관리
개발·시스템—사이트 개발, 서버·결제·알림톡 연동, 헤르메스, 유지보수
홍보·마케팅작업 영상·사진 제공네이버 블로그·인스타·유튜브 개설, 콘텐츠 제작, 자동 발행, 성과 관리
운영 판단가격, 공임, 환불 결정운영 데이터·리포트 제공

AI는 김씨 아래에서 역할별로 나뉘어 돌아갑니다. 개발, 분재 지식(상품 설명·관리 가이드·답변 초안), 마케팅(콘텐츠 계획·대본·글), 운영(발송·송장·재고), CS 1차, 그리고 이들을 묶는 총괄입니다.

쉽게 말하면홍씨는 이 구조를 알 필요가 없습니다. 텔레그램 하나만 보시면 됩니다. "이 나무 사리 견적 확인해 주세요", "작업 사진 올려 주세요", "이 손님 문의는 사람이 봐야 합니다" — 이 세 종류의 메시지에만 답하시면 됩니다.

운영 비서, 헤르메스. 헤르메스(Hermes)는 텔레그램으로 말을 걸면 클로드(AI)를 불러 일을 하는 오픈소스 비서입니다. Nous Research가 만들었고, 텔레그램 봇 토큰과 클로드 API 키만 넣으면 돌아갑니다. 김씨 맥미니에 이미 설치돼 있습니다. 일은 두 갈래입니다. "소사나무 새 상품 등록해", "이번 주 쇼츠 3개 올려" 같은 운영 작업은 바로 실행하고 보고합니다. 화면을 바꾸거나 기능을 더하는 코드 수정은 수정 제안을 올리고 → 자동 검토 → 시험 사이트 → 김씨가 "배포"라고 해야 운영 사이트에 반영됩니다. 이 승인 한 단계가 운영 사이트가 갑자기 깨지지 않게 하는 안전장치입니다.

네이버 블로그는 공식 글쓰기 기능(API)이 없어서 브라우저를 자동으로 조작해 발행합니다. 네이버가 제재하는 건 기계로 찍어내는 대량 글이고, 주 1~2편은 그 범위에 들지 않습니다. 실제 작업 사진이 든 긴 글로 쓰고, 발행 시간을 매번 달리하고, 같은 글을 다른 채널에 그대로 복사하지 않는 게 유지 조건입니다. 만에 하나 검색 누락이 생기면 서브 계정으로 이어갈 수 있게 원본은 사이트 쪽에 보관합니다.

비용과 주의. 헤르메스는 맥미니나 서버에 24시간 떠 있어야 하고, 클로드 API 요금은 종량제입니다. AI 여러 개가 하루 종일 돌면 월 수십만 원이 될 수 있어 역할별로 모델을 나눕니다. 헤르메스는 빠르게 바뀌는 프로젝트라 한 달에 한 번 점검합니다. 이 비용은 김씨 쪽 운영 항목입니다.
